# B8A1 - Problem Solving with TypeScript & OOP

## Assignment Overview

This repository contains my solutions for the B8A1 TypeScript assignment. I have practiced different TypeScript concepts through eight programming problems.

### Topics Covered

- Optional and default parameters
- Union types and type narrowing
- Readonly tuples
- Generics and rest parameters
- Interfaces and array methods
- Generic functions with keyof
- Classes, inheritance, and access modifiers
- Promises and asynchronous programming
